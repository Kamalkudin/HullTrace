Review port visits, inspections, voyages and radio identities from your own records.

UTF-8 CSV, up to 1 MB (1,048,576 bytes). Records stay in this view until you leave or reload.

CSV column guide

Include kind, source (a web address) and imo in every row. Include the following columns for each kind of record.

  • port — date, port
  • inspection — date, condition, deficiency
  • voyage — container, vessel
  • radio — month, mmsi

Use YYYY-MM-DD for dates and YYYY-MM for months. A single file can include several record types.
